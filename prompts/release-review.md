# Release review

```text
Use $release-review for [RELEASE CANDIDATE].

Review RELEASE_CHECKLIST.md, SECURITY_CHECKLIST.md, TESTING_GUIDE.md, accepted decisions, current status, release notes, and exact artifacts. Verify clean commit state, versioning, dependency and secret audits, tests, builds, hashes, signing, notarization, installer behavior, launch, upgrade, rollback, and disclosures.

Record each gate as Passed, Failed, Not run, or Manual verification pending, report blockers first, and return PASS, PASS WITH ADVISORIES, or FAIL. Do not tag, sign, upload, publish, or weaken a gate.
```
