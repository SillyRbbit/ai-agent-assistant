capacity and API spending/balance. It displays only Not connected and explicitly
illustrative Unverified states. No numeric capacity, percentages, currency amounts,
countdowns, sync timestamps or connection controls are permitted.

range and example-state selectors cannot change these placeholders. Subscription
allowance, request/token rate limits, spending, budgets and balances are different
measures. Headless execution is not another usage pool. Absence is not zero.
