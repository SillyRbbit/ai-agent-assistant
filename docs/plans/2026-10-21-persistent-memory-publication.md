and Per-Bot Memory milestone. This is publication of existing accepted work plus
its narrowly approved gate maintenance, not a new product increment. Preserve
original complete/valid acceptance, C7, failed predecessor, admission, historical

## Snapshot and publication contract

The original completed memory route binds one HEAD and index. Staging cannot be
silently treated as cached-stat drift. The separately authorized publication
reader preserves that historical contract and original state. It verifies a frozen
accepted snapshot, original evidence hashes, affected maintenance checks and review.
Current publication is separately bound to a complete workspace manifest and exact
Git blob identities. The supported phases are prepared, fully staged and committed;
partial staging, unknown flags, malformed indexes, unrelated content, missing files
and unsupported ancestry reject. A commit must have the exact reviewed tree and
recorded parent list, rather than merely descend from the old baseline.

If current main requires integration, one separately reviewed snapshot records the
exact existing publication parent and immutable upstream parent. Accepted product
source remains byte-identical. Upstream dependency/documentation changes retain
upstream provenance and require applicable merged-head checks; historical C7 is not
claimed to have run against changed dependencies. Original reports are immutable.
Records are append-only, content-addressed and confined to the memory checkout.
They preserve same-user workflow integrity, not malicious-same-user authentication.
