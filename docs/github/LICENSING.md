# Cortexa licensing decision record

Status: No open-source license selected
Last reviewed: 2026-07-16

## Current decision

The project owner has not selected an open-source, source-available, or
commercial license for this repository. No license grant may be inferred from
repository access, source visibility, issue participation, or a development
build.

Until explicit terms are selected:

- do not describe Cortexa as open source;
- do not copy, modify, redistribute, package, or publish repository content
  outside an authorized project workflow;
- accept external code contributions only after explicit maintainer
  coordination and rights review;
- treat license selection and dependency-license review as blockers for a
  production release or public contribution program.

This record documents repository policy; it is not legal advice and does not
replace owner or counsel review. D-047 in `DECISIONS.md` is the durable decision.

## Resolution gate

A later licensing increment must identify the copyright owner, contribution
terms, selected license text, dependency compatibility, documentation and
package metadata changes, release impact, and rollback. It must not add a
license by inference or convenience.
