## Counting and availability

Total is input plus output. Cached input is already included in input; reasoning is already included in output. Cumulative snapshots replace earlier revisions; deltas are canonicalized before filtering. Historical numeric decreases are rejected even across absence states. Unavailable projected through empty daily buckets remains Unavailable; absence is never imputed as zero.

Zero means an explicitly supplied zero. Missing means incomplete coverage; Unavailable means not supplied; Unverified means unsupported evidence. Failed/cancelled activity contributes to token totals but is excluded from completed-task averages. Incomplete task coverage keeps the average Missing. Unknown chart values appear as gaps and do not create proportional segments.

The examples use a fixed fictional UTC end of 2026-10-01 exclusive, with starts 2026-09-24 and 2026-09-01. Simulation totals are 1,750 and 3,080 sample tokens for 7 and 30 days. These are fabricated fixtures, not retained Step A or account values.
