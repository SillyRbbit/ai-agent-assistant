# Session start

1. Read `AGENTS.md` and every file in its required reading order.
2. Inspect Git branch, working-tree changes, and recent commits.
3. Check Node, npm, Cargo, Rust, and platform prerequisites.
4. Run the narrowest baseline check relevant to the requested task.
5. Compare code and test evidence with `HANDOFF.md` and `PROJECT_STATUS.md`.
6. Report the current state, one session goal, explicit non-goals, expected files, verification commands, and blockers.
7. Do not edit until the baseline and scope are clear.

Use `docs/workflows/START_SESSION.md` as the detailed runbook.
