# Conductor animation sources

`original.png` preserves the owner-approved source byte-for-byte. `atlas.png` is the
editable four-pose source; `animation.json` records the 2×2 frame layout and timings.
`atlas.webp` is lossless runtime data: visible RGB and alpha are unchanged; invisible
RGB under alpha zero may normalize. Neutral, closed eyelids, raised free hand and
lowered baton preserve the indigo/gold identity, bow tie and coordination emblem.

This is the existing AgentOrchestrator's presentation, not a configurable AgentId.
Runtime state comes from accepted overall workflow snapshots. No profile, provider,
permission, routing or execution authority is represented by the artwork.
